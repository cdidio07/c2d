Accessibility Statement

Last updated: September 2026

C2D Partnerships is committed to making this website usable by the widest possible audience, including people who use assistive technology.

Standards

This site is built to conform to the Web Content Accessibility Guidelines (WCAG) 2.2 at Level AA, including semantic HTML structure, keyboard-operable navigation and interactive components, visible focus states, sufficient color contrast, descriptive alternative text for images, and support for reduced-motion preferences.

Ongoing Work

Accessibility is an ongoing effort. If you encounter a barrier while using this website, please let us know so it can be corrected.

Contact

To report an accessibility issue, contact cdidio@carlodidio.net.
